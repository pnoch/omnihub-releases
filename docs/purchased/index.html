What happens next

  1. We email the key to the address you used at checkout — usually within a minute.
  2. In OmniHub, open Settings → Licence and paste it.
  3. Press Activate. Downloads and playback unlock straight away.

The key is issued for the device code you entered, so it will not work on another device. Keep the device code shown in the app: after a reinstall it restores this licence without a reissue.

No email after a few minutes? Check your spam folder, then reply to the Paddle receipt or write to support@siamcreations.app and we will sort it out.
